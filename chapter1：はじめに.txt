## はじめに

本書では、**Pythonを使ったサーバーレス開発の基礎**として、
「データ送信者 → SQS → Lambda → S3」のシンプルなETL処理を構築します。

対象読者は、**Pythonでの基本的なプログラミング経験（クラス、関数、例外処理）があるが、サーバーレス開発やETL処理は初めて**という方です。
ローカル開発環境の構築から**実際のAWS環境へのデプロイまで**を一通り体験し、
**本格運用可能な**プロジェクトを完成させることをゴールとします。

## 前提条件・開発環境

本書を進めるために、以下の環境が必要です。

- Docker Desktop がインストール済み
- Python 3.12+ がインストール済み  
- git コマンドが使用可能
- AWSアカウントを持っている

### 開発環境について

本書は macOS での開発を例に解説していますが、Docker を使用するため **Windows/Linux でも同様に動作します**。
エディタは Visual Studio Code を使用していますが、お好みのエディタで問題ありません。


## 本書で採用する構成の理由

AWS Lambdaを使ったデータ処理では、以下のような課題に直面することが多いです。

* **Lambda関数の開発とテストが手間**で、デプロイしないと動作確認ができない
* **SQSのイベント形式やエラーハンドリングに悩む**
* **S3への出力処理にクセがあり、権限やフォーマットで詰まる**
* **CodePipelineなど既存のCI/CDが複雑すぎて学びにくい**

そこで本書では、以下のようにシンプルかつ再利用可能な構成を採用しました。

* Poetry + Docker によるローカル開発環境
* JSON → JSONバリデーション → CSV変換 → S3アップロードのETL処理テンプレート
* AWSコンソールでの手動構築による実践的な理解
* GitHub Actions によるCI/CD自動化


## 本書のスコープ

本書で扱う範囲は以下のとおりです。

* LambdaでETL処理を構築し、CSVをS3に保存する一連の処理
* Docker + Poetry によるローカル開発環境のセットアップ  
* pytestによるローカルテスト
* AWSコンソールでのSQS、Lambda、S3リソースの作成と設定
* GitHub Actionsによる自動テスト・デプロイ
* 基本的な監視・トラブルシューティング

## 本書で扱わないこと

以下の内容は本書では取り上げません。

* Pythonの基本文法やvenv/pipの使い方
* AWSアカウント作成や基本的なAWS知識
* IAMロールやポリシーの高度な設計
* Step FunctionsやAthenaなどの高度なAWS連携  
* 大規模本番環境での高度なモニタリング設計
* セキュリティの詳細設計やコスト最適化


## 本書のゴール

本書を最後まで読むことで、以下のことができるようになります。

* PythonでLambda関数をローカルから開発・テストできる
* SQSイベントをトリガーに、CSVを生成してS3へ保存するETL処理を構築できる
* AWSコンソールで必要なリソースを構築し、実際のAWS環境にデプロイできる
* GitHub Actionsを用いた自動デプロイの仕組みを学べる
