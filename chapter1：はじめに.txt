## 📘 はじめに
本書では、**AWS Lambda × SQS × S3** を組み合わせて「実務でも使える ETL 処理テンプレート」を構築します。
Python製のLambda関数をローカルで開発し、テストを行い、
GitHub Actionsを使って自動デプロイするところまでを
実際に手を動かしながら学べる構成です。


## 📌 対象となる読者

* Pythonでサーバーレス（Lambda）開発を始めたい方
* SQS → Lambda → S3 の流れでETL処理を実装してみたい方
* Docker × Poetry を使ったローカル開発環境を構築したい方
* GitHub Actionsを使ってCI/CDに入門したい方
* AWSコンソールに依存しない形で、**コードベースで構成管理したい方**

LambdaやSQSなどのAWSサービスの基本をある程度理解している方を想定していますが、
各章では、背景や意図にも触れながら解説します。


## 💡 本書で採用する構成の理由

AWS Lambdaを使ったデータ処理の構築では、
以下のような課題に直面することが少なくありません。

* **Lambda関数の開発とテストが手間**で、デプロイしないと動作確認ができない
* **SQSのイベント形式やエラーハンドリングに悩む**
* **S3への出力処理にクセがあり、権限やフォーマットで詰まる**
* **CodePipelineなど既存のCI/CDが複雑すぎて学びにくい**

そこで本書では、以下のようなシンプルかつ再利用可能な構成を採用しました。

* Poetry + Docker によるローカル開発環境
* JSON → CSV変換 → S3保存のETL処理テンプレート
* GitHub + GitHub Actions を使ったCI/CD自動化

構成のシンプルさと実用性のバランスを意識しているので、
「とりあえず動く」だけでなく「育てられる」プロジェクトになります。

## 🎯 本書のスコープ

本書では、以下の範囲に絞って解説します。

* LambdaでETL処理を構築し、CSVをS3に保存する一連の処理
* Docker + Poetry によるローカル開発環境のセットアップ
* pytestによる自動テストと、GitHub ActionsによるCI/CDパイプラインの構築


## 🚫 本書で扱わないこと

以下の内容は本書では取り上げません。必要に応じて、別の資料や記事をご参照ください。

* AWSコンソールでのGUI操作やIAMロールの詳細設定
* Step FunctionsやAthenaなどの高度なAWS連携
* 本番環境でのモニタリング・アラート設計


## 🏁 本書のゴール（できるようになること）

本書を最後まで読むことで、以下のことができるようになります。

* PythonでLambda関数をローカルから開発・テストできるようになる
* SQSイベントをトリガーに、CSVを生成してS3へ保存するETL処理を構築できる
* GitHub Actionsで、CI/CDを含む自動デプロイの仕組みを構築できる

「Lambda × SQS × S3 をコードベースで扱いたい」という方にとって、
最初の一歩をしっかりサポートできるテンプレートになっています。
