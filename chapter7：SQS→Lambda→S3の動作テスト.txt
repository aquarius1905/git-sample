## はじめに

前章でAWSリソースの作成とLambda関数のデプロイが完了しました。
本章では、実際にSQSにメッセージを送信し、Lambda関数が正常に動作してS3にCSVファイルが保存されることを確認します。

また、CloudWatchログを使った動作確認の方法や、エラー発生時のトラブルシューティング手順についても解説します。


## 本章の流れ

1. SQSキューへテストメッセージを送信
2. Lambda関数の実行を確認（CloudWatchログ）

## トラブルシューティング

### よくある問題と対処法

#### 問題1：Lambda関数が実行されない

**症状：**
- SQSにメッセージを送信してもLambdaが起動しない
- CloudWatchログにエントリが作成されない

**確認ポイント：**
1. Lambda関数のトリガー設定を確認
```bash
aws lambda list-event-source-mappings \
  --function-name lambda-etl-processor
```

2. トリガーが有効化されているか確認
   - Lambdaコンソール → 設定 → トリガー
   - 「有効」になっているか確認

3. SQSキューのポリシー確認
   - Lambda関数に`sqs:ReceiveMessage`権限があるか

**対処法：**
- トリガーを削除して再作成
- IAMロールに`AmazonSQSFullAccess`が付与されているか確認

#### 問題2：S3へのアップロードに失敗

**症状：**
```
AccessDenied: Access Denied
```

**確認ポイント：**
1. Lambda実行ロールにS3権限があるか
```bash
aws iam list-attached-role-policies \
  --role-name lambda-etl-processor-role-xxxxx
```

2. 環境変数の設定を確認
   - `S3_BUCKET_NAME`が正しいか
   - バケット名にタイポがないか

**対処法：**
- IAMロールに`AmazonS3FullAccess`を追加
- 環境変数を再設定

#### 問題3：タイムアウトエラー

**症状：**
```
Task timed out after 3.00 seconds
```

**原因：**
- Lambda関数のタイムアウト設定が短すぎる
- 処理するデータ量が多い

**対処法：**
1. Lambda関数の設定 → 一般設定 → タイムアウトを延長（例：5分）
2. SQSキューの可視性タイムアウトも調整（Lambdaタイムアウト × 6倍推奨）

#### 問題4：メモリ不足エラー

**症状：**
```
Runtime exited with error: signal: killed
```

**対処法：**
- Lambda関数の設定 → 一般設定 → メモリを増やす（例：512MB）

#### 問題5：インポートエラー

**症状：**
```
Unable to import module 'app.main': No module named 'app'
```

**原因：**
- デプロイパッケージの構造が間違っている
- ハンドラー設定が間違っている

**対処法：**
1. デプロイパッケージを再作成
```bash
./deploy.sh
```

2. zipファイルの内容を確認
```bash
unzip -l lambda-etl-function.zip
```

期待される構造：
```
app/
  __init__.py
  main.py
  core/
    __init__.py
    config.py
    ...
```

3. ハンドラー設定を確認
   - 正しい設定：`app.main.lambda_handler`

## 複数メッセージの連続テスト

実運用を想定して、複数のメッセージを連続して送信してみましょう。

### テストスクリプト（Bash）

```bash
#!/bin/bash

QUEUE_URL=$(aws sqs get-queue-url --queue-name lambda-etl-queue --query 'QueueUrl' --output text)

# 5件のメッセージを連続送信
for i in {1..5}
do
  echo "メッセージ $i を送信中..."
  aws sqs send-message \
    --queue-url $QUEUE_URL \
    --message-body "{
      \"records\": [
        {
          \"user_id\": $i,
          \"name\": \"テストユーザー$i\",
          \"email\": \"test$i@example.com\"
        }
      ]
    }"
  sleep 2
done

echo "送信完了"
```

### 実行と確認

```bash
# スクリプトに実行権限を付与
chmod +x test_batch.sh

# 実行
./test_batch.sh

# S3バケットに5つのCSVファイルが作成されることを確認
aws s3 ls s3://lambda-etl-bucket-[your-name]-[date]/etl-output/
```
